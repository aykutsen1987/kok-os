Kök OS User Guide

Kök OS is a lightweight operating system designed to run smoothly on older computers and tablets. It can run Windows programs (.exe) and Android apps (.apk).

1. Getting started

The Kök Welcome window opens at startup. To install permanently, click Install Kök OS on the desktop and follow the wizard. You can choose the system language in the installer.

2. Windows programs (.exe)

Double-click an .exe or .msi file. Each program runs in its own separate environment. Some programs (especially heavy games and copy-protected software) may not be compatible.

3. Android apps (.apk)

Open Android Apps. The Android environment is set up on first use (about 1 GB download). You can also double-click an .apk file to install it.

At least 4 GB of RAM and real hardware are recommended for Android. It may not work inside virtual machines.

4. Language

Kök Settings → Language switches between Turkish and English at any time (log out and back in to apply).

5. Speed on older computers

Kök OS picks a Light or Standard profile from your memory size. Change it in Kök Settings → General. Rounded window corners can be turned off in Appearance.

6. Tablets and laptops

Kök Settings → Hardware: screen rotation, on-screen keyboard, Bluetooth, Wi-Fi and power settings.

7. Updates

Kök Update updates system packages. Security updates are applied automatically on an installed system.

8. Troubleshooting

Health Check shows which component is not working. Create Error Report prepares a detailed report for the developer.
